# إدارة البوفيه — الإصدار 2.0.0

برنامج إدارة بسيط بأربع شاشات فقط

1. المنيو: كل الأصناف مجمعة حسب الفئة، سعر البيع، وسعر تكلفة اختياري يمكن كتابته من الجدول نفسه. يمكنك إضافة أصناف وتعديلها وتعديل أسماء الفئات.
2. الوصفات والخامات: نفس وظائف إدارة الخامات ومقادير الوصفات وتكلفتها الموجودة في الإصدار السابق.
3. المعدات: قائمة المعدات وحالتها وملاحظاتها.
4. النوتة: ملاحظات بعنوان ونص حر. اكتب أي تفاصيل بنفسك، مثل عدد أقساط جهاز وتاريخ آخر قسط. لا توجد حسابات أقساط أو حقول إجبارية لهذه التفاصيل.

الإعدادات متاحة من زر الترس أعلى الشاشة، وتشمل النسخ الاحتياطي والمراجعة مع ChatGPT وتسجيل الدخول والمزامنة.

## رفع النسخة إلى GitHub Pages

- فك الضغط وارفع **كل الملفات الموجودة داخل ZIP** إلى جذر مستودع البرنامج `W-`، مع استبدال الملفات القديمة التي تحمل نفس الاسم.
- تأكد من ظهور ملفات `index.html` و`app.js` و`simple.css` و`manifest.webmanifest` و`sw.js` وملفي الأيقونات في الجذر.
- بعد النشر حدّث الصفحة. لو أيقونة الآيفون لم تتحدث، أزل اختصار الشاشة الرئيسية القديم وأضف التطبيق من Safari مرة أخرى، بعد التأكد من حفظ بياناتك ومزامنتها.

## البيانات والمزامنة

- يحافظ الإصدار على مفتاح التخزين المحلي نفسه وقاعدة بيانات Supabase نفسها المستخدمة في النسخة السابقة.
- الأصناف والأسعار والخامات والوصفات والمعدات والموردون وسجلات الشراء والقرارات القديمة لا تُحذف من البيانات. تختفي فقط الشاشات غير المطلوبة من الواجهة.
- بعض الأفكار التي سبق تعديلها في الشاشة القديمة تنتقل إلى النوتة تلقائيًا. لا تضاف أمثلة الأفكار الافتراضية للنوتة.
- الملاحظات الجديدة تحفظ محليًا وتدخل في نفس مزامنة الحساب. لا يلزم إنشاء مشروع Supabase جديد.
- قبل رفع النسخة، من الإعدادات نزّل نسخة احتياطية من بياناتك على الجهاز الذي تستخدمه حاليًا.
- اختُبرت واجهة الموبايل والكمبيوتر، كتابة التكلفة، إضافة الملاحظات وتعديلها وحذفها، تعديل الفئات والمنتجات، وقراءة بيانات نسخة قديمة. لم يُجر اختبار مزامنة حقيقي باستخدام حسابك.
