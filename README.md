# إدارة البوفيه — V1.5.0

## ما الجديد؟
- المنيو جدول واضح ومقسّم إلى عناوين فئات؛ عنوان كل فئة فوق جدولها مع عدد الأصناف.
- إدارة الفئات من شاشة المنيو: إضافة فئة، تعديل اسمها، وحذف الفئة الفارغة فقط.
- عند تعديل اسم فئة، تتغير فئة الأصناف التابعة لها بدون تغيير أسعارها أو بيانات شرائها.
- صفحة مراجعة البيانات تحتوي زرًا واحدًا فقط «مراجعة مع ChatGPT» يقوم بتصدير ملف JSON، يُرفع يدويًا للمحادثة.
- مكان الشراء ومدينة المورد حقول نصية حرة بلا خيارات جغرافية مفروضة أو أسماء أماكن افتراضية.
- الاسم الظاهر في الواجهة صار «إدارة البوفيه» بدل ربطه بمدينة؛ مع أيقونة التطبيق التي جرى اختيار تصميمها.

## الأمان والحفاظ على البيانات
- ملف التحديث لا يمس تطبيق البيع الآخر ولا برنامج الجرد القديم.
- تم الاحتفاظ بمفاتيح تخزين بيانات التطبيق المحلية (`siwa-admin-state-v1`, `siwa-admin-cloud-v1`, `siwa-admin-session-v1`) **بدون تغيير** حرصًا على البيانات والجلسة الحالية. هذه أسماء تقنية داخلية فقط، لا تظهر في الواجهة.
- اتصال Supabase ما زال بالمشروع المنفصل نفسه، ولم يُنشأ مشروع جديد، ولم يُطلب أي مخطط قاعدة بيانات جديد.
- تتم مزامنة مصفوفة `categories` داخل نفس سجل البيانات السحابي المحمي الموجود بالفعل.
- عند فتح بيانات V1.4 القديمة يتم اشتقاق الفئات منها تلقائيًا. الأرقام والأسعار والديون غير معنية بالتحديث.
- أسماء الأماكن القديمة التي غُيّرت بواسطة المستخدم لا يتم مسحها تلقائيًا. أما بيانات الأماكن الافتراضية القديمة غير المعدّلة (updatedAt=1)، فتُترك فارغة ليكتب المستخدم مكانه.
- لا يحتوي التطبيق على مفتاح سري لخادم؛ مفتاح Supabase الموجود هو المفتاح العام Publishable، والصلاحيات محكومة بالمصادقة وRLS.

## النشر على GitHub Pages
1. افتح مشروع الإدارة فقط `mohamed9090900/W-` ثم اذهب لجذر فرع `main`.
2. من `Add file → Upload files` ارفع محتويات الأرشيف، وليس ملف ZIP نفسه. وافق على استبدال الملفات المتشابهة.
3. بعد نجاح Commit، افتح رابط التطبيق وقم بتحديث الصفحة. قد تحتاج لإغلاق التطبيق وإعادة فتحه لأن النسخة مثبتة كـPWA.
4. **قبل التحديث** نزّل نسخة احتياطية من الإعدادات ← النسخ الاحتياطي، وتأكد من ظهور «متزامن» بعد نشر النسخة الجديدة.

إذا كانت هناك بيانات مهمة على الجهاز، لا تمسح بيانات المتصفح ولا تحذف التطبيق قبل أخذ النسخة الاحتياطية.
