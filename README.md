# إدارة البوفيه — V1.6.0

نسخة كاملة جاهزة للرفع إلى GitHub Pages. فك الضغط وارفع **كل الملفات الموجودة في جذر الحزمة** مرة واحدة إلى المستودع الحالي.

## التحديثات
- جدول بيانات المشتريات مجمّع تحت عناوين فئات المنيو القابلة للتعديل من شاشة المنيو.
- واجهة مناسبة للموبايل بأربعة أعمدة واضحة بدل جدول يمتد خارج الشاشة.
- قائمة شراء مقترحة مجمّعة حسب الفئات أيضًا، مع قسم مستقل لخامات الوصفات.
- تسجيل شراء فعلي بخمس خانات: الصنف، الكمية بوحدة الشراء، المبلغ الإجمالي، المكان، التاريخ. الكمية تُحوّل داخليًا لوحدات المخزون.
- بانر رئيسي مختصر بالشعار والعنوان وزر شراء واحد، بدون سرد أسماء الأقسام.
- ملفات أيقونة جديدة بأسماء مميزة لتجاوز الكاش على الآيفون، وتحديث manifest و Apple touch icon.

## أمان البيانات والمزامنة
- مفتاح localStorage لم يتغير. احفظ نسخة احتياطية من البرنامج قبل النشر.
- إعدادات Supabase وRLS لم تتغير ولم يتم لمس المشاريع القديمة.
- عدم استخدام بيانات شراء فعلية إذا لم تُسجل: الخطة حساب تقديري وليست فاتورة.

## بعد الرفع
1. انتظر نشر GitHub Pages ثم افتح الموقع وحدّث الصفحة.
2. لظهور الأيقونة الجديدة على شاشة الآيفون: احذف **اختصار الشاشة الرئيسية القديم فقط** (لا تحذف بيانات الموقع من إعدادات Safari)، ثم افتح الموقع من Safari واختر مشاركة ← إضافة إلى الشاشة الرئيسية. يفضل أن تتأكد أولًا أن بياناتك ظهرت وأنك سجّلت نسخة احتياطية.
3. لا تغيّر إعدادات Supabase أو حساب الدخول.
