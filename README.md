# إدارة البوفيه — V1.5.2 (النسخة الكاملة)

## التعديل الجديد
- صفحة «التجارب والقرارات» تعرض جميع الأفكار في قائمة واحدة دون تصنيفات أو خانة «القسم».
- إضافة وتعديل الفكرة: الموضوع، الحالة، التفاصيل، وخطوات التنفيذ فقط.
- حالة الفكرة ظاهرة في بطاقة الفكرة، وتقدم المهام محفوظ كما كان.
- بيانات الفئات القديمة لا تُحذف من الملفات المحفوظة أو السحابة، لكن لا تظهر في الواجهة ولا يُطلب إدخالها.
- تم الإبقاء على المنيو ومشتريات 7 أيام وبيانات الدخول والمزامنة كما هي.

## النشر على GitHub
1. من داخل البرنامج القديم، نزّل نسخة احتياطية أولًا.
2. فك الضغط عن ملف ZIP.
3. ارفع جميع الملفات الموجودة **داخل المجلد** إلى جذر المستودع `mohamed9090900/W-`، واستبدل الملفات الموجودة.
4. اضغط Commit changes، ثم حدّث الصفحة بعد النشر؛ وقد يتطلب تحديث PWA فتحها مرة ثانية لتحديث التخزين المؤقت.

## ملاحظة مهمة
المزامنة مرتبطة بمشروع إدارة البوفيه المستقل الحالي ولم تتغير إعداداتها. ملفات النسخة لا تعدل قاعدة البيانات تلقائيًا؛ بيانات المستخدم تبقى في التخزين المحلي وSupabase.
