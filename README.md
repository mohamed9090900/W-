# إدارة بوفيه سيوة — V1.4.0

## الجديد
- مشروع مزامنة مستقل على Supabase (Siwa Buffet Manager).
- عنوان المشروع والمفتاح العام مثبتان في الكود، بلا أي إمكانية للتغيير إلى مشروع البوفيه القديم من شاشة البرنامج.
- الدخول ببريد حساب الإدارة وكلمة مروره، والمزامنة تلقائية بعد الدخول وعند عودة الإنترنت.
- صلاحيات RLS: كل حساب يرى بياناته فقط، وليس للزوار صلاحية للجدول.
- المنيو جدول وإضافة صنف بخمس خانات وبيانات الكرتونة داخل شاشة المشتريات.
- نسخة احتياطية، تصدير مراجعة ChatGPT، عمل محلي عند انقطاع الإنترنت.

## لتشغيل المزامنة
1. أنشئ مستخدم الإدارة بنفسك في Supabase: Authentication > Users > Add user.
2. يفضل تعطيل التسجيل المفتوح في Authentication > Providers > Email (إن كان الخيار متاحًا).
3. افتح البرنامج من GitHub Pages بعد رفع ملفات هذه الحزمة؛ اذهب إلى الإعدادات والنسخ، وأدخل البريد وكلمة المرور.
4. على الأجهزة الأخرى، افتح نفس الرابط وسجل بنفس الحساب، ثم انتظر حالة «متزامن».
5. نزّل نسخة احتياطية قبل استيراد بيانات أو التبديل بين الإصدارات.

## السلامة
- هذا المشروع لا يقرأ أو يعدل بيانات Buffet V9 Online أو El-gard.
- مفتاح sb_publishable عام. لا تستخدم أبدًا service_role في الواجهة.
- ملف SQL توثيقي؛ تم تنفيذ هذا المخطط بالفعل في مشروع الإدارة الجديد.
- الربط المباشر بمحادثة ChatGPT غير مفعّل؛ يمكنك تصدير البيانات للمراجعة هنا بدون أي API مدفوع.
- التحديث على GitHub يحتاج رفع هذه الملفات إن لم يسمح الربط بعملية كتابة.
